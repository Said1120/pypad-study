# 真实 iPad 五分钟验收清单

适用环境：iPadOS 17+、Safari，以及从 Safari 添加到主屏幕后的 PyPad PWA。请在 Cloudflare 预览地址生成后执行，并记录 iPad 型号、iPadOS 版本、日期和结果。

## 联网准备

1. 用 Safari 打开预览地址，确认页面显示“Python 已就绪”和“可离线使用”。
2. 将网页添加到主屏幕，再从主屏幕图标打开。
3. 运行 `print("你好")`，确认输出立即出现。
4. 运行 `name = input("名字：")` 和 `print(name)`，输入中文并确认输出正确。
5. 运行 `while True: pass`，点“停止”，确认两秒内回到“运行已停止”或“Python 已就绪”。

任意一项失败时停止发布，保留屏幕录制、错误文字和复现代码，不把产品静默降级为无交互输入或不可中断版本。

## 离线与恢复

1. 打开飞行模式，彻底关闭主屏幕 PWA，再重新打开。
2. 确认已有项目仍存在，Python 能就绪，`print(1 + 1)` 输出 `2`。
3. 修改代码后切到其他应用约十秒，再返回，确认修改仍在；关闭重开后再次确认。
4. 恢复网络，在“扩展包”中准备 NumPy；完成后再次进入飞行模式，运行 `import numpy as np; print(np.arange(3))`。

## iPad 操作体验

1. 横屏和竖屏各切换一次，确认编辑器、文件抽屉和输出区没有被安全区域或软键盘遮住。
2. 用屏幕键盘编辑缩进、括号和中文字符串；如有外接键盘，再验证 `⌘S`、`⌘Enter`、`⌘.`、`⌘P`、`⌘F`。
3. 新建 `helper.py`，在 `main.py` 中导入它并运行。
4. 导出项目 ZIP，再导入该 ZIP，确认两个文件内容和入口文件正确。
5. 运行一个 Matplotlib 折线图，确认图像出现在输出区。
